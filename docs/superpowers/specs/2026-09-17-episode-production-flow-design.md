# 分集详情页五阶段制作流程设计

日期：2026-09-17
状态：设计已在对话中确认，待用户审阅本文；本轮只实现可交互的前端流程，不接入真实 AI 生成。

## 目标与现状

面向制作一集 AI 漫剧的个人创作者，把“本集小说 → 剧本 → 角色/场景/道具 → 分镜脚本与分镜图 → 分镜视频”变成可编辑、可审核、可回退的连续工作台。用户应始终知道当前采用的内容、待核对的对象、下一步以及上游修改的影响。

当前 `EpisodePage.tsx` 是七段连续滚动内容：剧本、角色、道具、场景、分镜脚本、分镜图、分镜视频。`EpisodeDraft` 只存一段剧本文本、三段资源备注、简单镜头文字和全局图片/视频提示，保存在本地浏览器存储；角色/场景/道具卡片从本剧资源库只读展示。页面没有真实生成、采用或依赖状态。当前 AI 配置页也是明确标注的界面演示。既有本地媒体导入、列举、预览桥接可以复用，但这轮不修改后端、任务接口、真实模型配置或其他制作工作台。

本设计只取代既有工作台布局规格中的**分集制作七段内容**；首页、项目详情、本剧资源库的既有布局和蓝白 Ant Design 视觉基线保持不变。项目、分集入口及现有数据不得丢失。此页面是“操作型工作台”，优先明确成果和操作关系，不增加装饰性卡片。

## 方案选择与页面结构

采用五个主阶段、阶段内保留细项的连续工作台。严格向导会妨碍逐镜返工，直接保留七个同级区块则难以表达剧本确认和素材图片审核。左侧阶段导航显示状态、当前阶段和待处理数量；右侧按阶段呈现可编辑成果、一个主要下一步动作、必要的说明与错误反馈。旧阶段可随时回看，点击导航不等于确认；桌面左栏固定，窄屏改为可横向浏览的阶段导航。进入页面时定位最近未完成/需复核阶段，首次进入定位小说输入。保留减少动态效果时的即时滚动和键盘焦点可见性。

| 阶段 | 核心输入与结果 | 人工关口 |
| --- | --- | --- |
| 1 小说与剧本生成 | 本集小说、剧本生成演示模型、可编辑的剧本候选；也可直接粘贴已有剧本 | 选用候选或继续人工编辑，不自动确认 |
| 2 剧本确认与素材拆解 | 剧本编辑/原文对照；画幅比例、视觉风格、素材分析演示模型；角色、场景、道具候选描述 | 确认剧本快照，再核对素材候选 |
| 3 素材图片 | 素材名称/描述及已有资源关联；文生图演示模型；逐项图片候选或导入媒体 | 每个必需素材选定图片、用途并确认 |
| 4 分镜脚本与分镜图 | 分镜脚本及分镜图演示模型；按镜头组织的文字、素材关联、时长；首尾帧或九宫格模式及图片候选 | 核对分镜文字与逐镜图片，静态顺序预览 |
| 5 分镜视频 | 图生视频演示模型；逐镜输入、进度、动态演示或导入视频、候选比较 | 逐镜选用结果；本轮不等于配音、剪辑或成片导出 |

画幅比例仅在第二阶段提供 `16:9` / `9:16` 选择，默认继承项目值，本集可调整；若不同于项目画幅，显示后续输出需统一的提示，不暗改项目设置。视觉风格默认取项目值，允许本集编辑。**不在分集页面增加清晰度输入**；既有项目清晰度配置不受影响。所有模型选择框仅包含清楚标注的演示选项；不把 AI 配置页的临时表单误称为已经连接的可用模型。

## 各阶段交互

### 1. 小说与剧本生成

小说原文独立保存，可贴入完整的本集范围，并显示输入长度；长文本不静默截断。用户可选择演示模型后点击“演示生成剧本”，得到标注为样例的候选文本；也可直接输入已有剧本。原文、候选和用户编辑的剧本是不同字段，重新演示生成只增加候选，不覆盖当前编辑内容。用户明确选择候选才替换编辑稿；替换前提示未保存改动。演示输出可引用原文片段，但不能声称做了准确的 AI 改编或完整小说理解。

### 2. 剧本确认与素材拆解

主编辑区提供剧本和按需展开的小说原文对照，保存反馈可见。点击“确认剧本”保存当时的剧本、画幅和风格快照；后续修改进入新草稿，已确认版本仍可查看。确认后用户选择素材分析演示模型，点击“演示分析素材”，得到可编辑的角色、场景、道具候选卡片，含类型、名称、描述、来源标记和状态。允许增删候选、纠正名称与描述；重复名称可关联本剧已有资源，不自动合并。确认素材候选时可选择仅供本集使用、关联已有资源或加入本剧资源库；加入后复用名称/描述及可持久引用的图片标识，避免跨集出现多个同名角色。已有资源保持原 ID，未确认的候选不写入资源库。

### 3. 素材图片

按角色、场景、道具分组，卡片上同时看到名称、描述、资源关联和图片状态。选择同一阶段的文生图演示模型，逐项演示生成图片候选，或选用已经导入本项目的图片；新文件导入可复用现有本地媒体桥接及其进度/失败反馈，不需新后端接口。选图与“确认素材可用”分开：用户核对身份、风格和用途后才确认。缺图时仍可编辑后续分镜草稿，但依赖该图的视频输入不能被当成已就绪。演示图标为示意，不可假称真实生成媒体；刷新时仅保存静态示例资源 ID 或项目媒体 ID，不把大图二进制写入浏览器存储。项目媒体缺失或不可用时呈现“需重新定位/替换”，不显示可用。

### 4. 分镜脚本与分镜图

选择分镜脚本演示模型，根据确认的剧本演示拆分有稳定 ID 的镜头卡；用户可增删、重排、编辑镜头目标、画面与动作、对白/声音提示、建议时长，并关联已确认的角色、场景、道具。镜头文字确认之后选择分镜图演示模型及制作方式；同阶段使用同一模型选择，新生成结果不覆盖已采用的镜头描述或旧图。

- **首尾帧方式：**以单镜为单位展示首帧和尾帧候选，分别核对动作发生前与完成后的状态；两张图可分别采用或替换。尾帧只是制作依据，是否能进入视频请求由未来真实模型能力决定；演示页不能承诺所有模型支持尾帧输入。
- **九宫格方式：**按当前镜头顺序组织每组最多九个不同镜头，超过九镜分组，不足九镜不编造额外镜头。保留整张九宫格候选供检查风格与叙事连续性；逐格拆分并核对格号、镜头 ID 和裁切结果，再分别采用。重排镜头后原格号和 ID 关系可见，不自动重绑到别的镜头。分格尺寸不足时标为“仅供分镜参考”，需要另备适用的单幅视频输入图。

两种方式可先后尝试，所有候选保留；切换方式不删除已采用图。视频阶段读取每镜选定且适用的单幅输入图，绝不把整张九宫格直接当作一镜输入。顺序静态预览用镜头图、文字和计划时长核对叙事，不伪装为动态视频或最终成片。

### 5. 分镜视频

按镜头显示剧本摘要、当前采用的分镜图、素材引用、计划时长和图生视频演示模型。用户主动逐镜启动演示生成，查看“准备中/生成中/待核对/失败”状态；结果可以演示动态预览、选择候选，或关联本项目真实导入的视频并播放。演示动态预览必须显著标明非真实视频媒体。单镜的候选选中不等于采用，选用后仍可返回修改并保留旧候选。汇总显示哪些镜头有选用结果、哪些需复核；“演示流程完成”不得写成“成片已完成”。配音、音乐、剪辑、检查、导出均在本轮范围之外。

## 状态、依赖与数据边界

阶段状态为“未开始 / 待核对 / 已确认 / 需复核”；生成演示的瞬时状态另记为“空闲 / 准备中 / 生成中 / 失败”，不要把任务进度和审核状态混为一个枚举。素材、镜头文字、首帧、尾帧、九宫格分格与视频候选分别记录审核/采用状态。单一推荐主操作随当前条件变化，按钮禁用时给出缺失条件和可前往的入口。任何阶段确认不会自动启动下一阶段的生成。

原文、编辑稿、已确认快照、候选、采用项、模型演示选择和素材/镜头稳定 ID 均为不同数据。按项目 ID 和分集 ID 命名空间保存有版本号的前端流程草稿；读取旧 `EpisodeDraft` 时无损迁移原有剧本、人物/道具/场景备注、镜头及图片/视频提示，不静默丢弃。保存失败（含浏览器存储容量不足）显示明确错误，不能假称已保存。项目资源引用优先保留资源 ID；图片/视频只存演示资源 ID 或本项目媒体 ID 和用途，不存文件路径、凭据和二进制。真实导入媒体重新打开时核对可用性，项目只读或本地服务未就绪时禁用需要写入/导入的操作，已保存的文本和示例仍可查看。

上游修改不删除旧成果：更改已确认剧本标记相关素材、分镜与视频“需复核”；更改某素材只影响引用它的镜头图/视频；更改某镜头文字或其已采用图片只影响该镜相关下游。视觉风格、画幅改动影响适用的视觉成果，模型演示选择变更只影响未来演示请求，不追溯改写旧结果。打开需复核项可对比原采用内容与新草稿，用户明确选择沿用或重新制作并确认；本轮不实现自动语义判定是否真的等价。

## 演示、异常与验收

页面常驻“交互演示：不会调用 AI，也不会产生模型费用”说明；所有模拟模型和候选带演示标签。演示生成以可重复、可编辑的样例驱动交互，不保证从任意输入准确抽取人物/场景/道具；不制造虚构的费用、服务商连接状态、视频时长或质量结论。若输入为空、剧本未确认、卡片缺关键描述、分镜图仅为低分辨率参考或视频输入不可用，操作给出具体原因。演示失败可手动重试且保留旧候选；离开页面、刷新和重新进入可恢复持久状态，不把刷新后的模拟任务装作仍在云端执行。

实现限定在分集页、必要的前端模型/组件和针对性样式/测试；不修改后端、真实任务系统、全局 AI 配置、项目详情、剪辑与导出。验证至少覆盖：旧草稿迁移；原文/候选/确认版隔离；五阶段导航与保存；项目与分集切换；资源关联与重复项；单镜首尾帧和尾帧能力提示；九宫格超过九镜分组、拆分/映射/重排；上游编辑导致局部需复核且不丢旧候选；演示与真实媒体边界；失败/重试/媒体缺失/只读；刷新恢复；键盘、窄屏及减少动态效果。类型检查和相关前端测试应通过；无真实 AI 效果的验收声明。
