# 工作台布局与 Ant Design 接入设计

日期：2026-09-17
状态：待用户审阅；此文档只描述本轮界面改动，不扩大产品功能范围。

## 目标与边界

在现有 Electron + React 工作台上统一蓝白色调，复用 Ant Design 的通用控件，并调整首页导航、项目管理、项目详情和分集制作的布局与交互。保持现有项目/分集/素材数据结构、桌面桥接、草稿自动保存、错误提示和禁用规则不变。AI 配置与其他制作工作台不在本轮重做范围内。工作区当前有未提交改动，实施时只触及相关文件，不清理或覆盖无关改动。

## 选择的方案

采用渐进接入：顶层 `ConfigProvider` 提供统一主题，目标页面的普通按钮、卡片、输入框、文本域、选择器等适合复用的控件改用 Ant Design；保留电影画幅提示、封面和流程导航等有领域含义的自定义结构。全面重写所有页面会扩大回归范围；仅把旧控件改成蓝色则无法实现组件复用。

设计模式是“操作型桌面工作台”。命名颜色：主蓝 `#1677ff`、深蓝文字 `#173b68`、正文 `#20334d`、次级文字 `#56708f`、内容白 `#ffffff`、工作区浅蓝灰 `#f5f8fc`，边线 `#d9e3ef`。Ant Design 的主色 token 为 `#1677ff`，页面样式从同一套 token 派生，不再散落不同的按钮蓝。中文优先使用 Windows 的 `Microsoft YaHei UI`，西文/数字使用 `Segoe UI`；页面标题约 24–30px，区块标题 17–22px，正文 13–14px。文案保留现有简体中文。这个项目的特征放在有序的七段制作流程、画幅信息和镜头内容上，不添加与创作无关的渐变、阴影或装饰卡片。

桌面布局（示意）：

```text
首页：[项目管理] [素材库 ▾] [AI 配置] │ 页面标题                 [新建项目] [打开项目]
                  角色／场景／道具     │ 最近项目卡片…

项目详情：剧集信息
          [项目名称                    │ 图片/视频风格（可编辑） │ 画面比例]
          [故事梗概（独占整行，可多行编辑）                         ]
          分集列表 / 本剧资源库

分集制作：[固定的七步导航] │ [故事剧本]
                          │ [角色]
                          │ [道具]
                          │ [场景]
                          │ [分镜脚本]
                          │ [分镜图]
                          │ [分镜视频]
```

整体左对齐，表单标签与内容左边缘对齐；项目名称长时允许换行或按空间合理截断，不压坏右侧字段。窄屏改为纵向编排，七步导航成为可横向滚动、贴近顶部的步骤条；风格和画幅换行，故事梗概仍占完整宽度。

## 页面与组件职责

- 应用入口只设置 Ant Design 的全局主题及中文 locale，不改变原有路由、运行状态和桥接。调整旧的全局 `button`/`input` CSS，使其不覆盖 Ant Design 控件；自定义控件继续有可见焦点。
- 首页侧栏让“素材库”成为真正的展开/收起控制，使用 `aria-expanded`、`aria-controls` 和明显的方向指示。默认展开；折叠时隐藏角色、场景、道具，当前素材种类保持原值；再次展开后可直接选原种类。点击“素材库”进入当前种类且展开，点击收起箭头只折叠，不改变页面。键盘可操作。
- 项目管理页把“新建项目”“打开项目”作为同组操作右对齐，窄屏允许自然换行；保留现有创建/打开命令、忙碌锁和错误反馈。最近项目卡片保留可点击语义和封面区别，卡片容器复用 Ant Design；避免把按钮嵌套在可点击卡片里。
- 项目详情的“剧集信息”不再渲染“关闭项目”按钮。标题下第一行采用项目名称为主要区域、右侧风格可编辑字段和只读画幅；第二行故事梗概横跨整个卡片并保持多行文本域，继续沿用现有保存逻辑和 2000 字上限。其余分集和资源列表沿用当前数据与动作。
- 分集制作保留七个独立内容块，同时挂载且按现有顺序排列，输入内容在滚动时不会卸载。左栏固定在可视范围内，右侧随页面纵向滚动。每块有稳定 id、可访问的标题和足够的滚动定位间距。左栏按钮对应具体区块；由当前可见区块驱动唯一高亮，而非用点击状态假定滚动已经完成。

## 滚动同步与动效

点击步骤时使用目标区块定位和原生平滑滚动；在系统设置“减少动态效果”时改为即时定位。手动滚动、触控板滚动和键盘滚动使用区块可见性/滚动位置更新高亮；临近区块交界时以顶部阅读线为准，页面到底时最后一项可正确高亮。点击后若用户中途手动滚动，以实际位置为准，避免导航高亮停在目标而内容停在别处。仅使用短暂的导航状态过渡，不对每块内容做无关的入场动画。

## 状态、失败与可访问性

保留服务未就绪、创建/打开失败、目录取消、草稿保存以及按钮禁用逻辑。组件迁移不改变受控输入的值和原有字段标签；若 Ant Design 的表单控件改变 label 关联，补齐 `id`/`htmlFor` 以维持可访问名称和现有测试定位。折叠菜单、步骤高亮和焦点有可辨状态；颜色对比、键盘焦点和 `prefers-reduced-motion` 均需检查。任何新增弹层继续遵循当前对话框的关闭与焦点行为。

## 验证与验收

先对现有交互补充/调整测试，再实施：素材库展开/收起与当前种类保持；项目操作组靠右；剧集信息没有关闭按钮且布局字段值保存；七段内容同时存在、点击导航滚动、滚动后导航更新、草稿在来回滚动后保持。运行类型检查、相关单元测试及 Electron 端到端测试。端到端测试沿用 `AVI_E2E_OFFSCREEN_WINDOW=1` 并断言窗口位于屏幕外，不把应用窗口弹到用户面前；截图也从屏幕外窗口采集。桌面与窄屏各核对一轮，修正后最多复查一轮。

验收标准是六项用户要求均可操作，已有项目/素材操作和数据未回归；不以 CSS 截图取代真实的双向滚动与键盘验证。
