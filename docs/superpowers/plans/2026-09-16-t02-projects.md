# T02 项目持久化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 先交付可验证的项目创建/打开/恢复，再接可靠草稿和媒体工作流。

**Architecture:** 保持 Electron main 的唯一权限边界；renderer 仅调用有限桥。FastAPI 按业务路由扩展认证后的 JSON 处理，Python 服务管理应用库、项目库、会话、短事务和 OS 写锁。现有运行时限制保持。

**Tech Stack:** 项目已锁定 Electron/React/TypeScript、FastAPI/Python 3.13、sqlite3、Windows 文件锁。

**Spec:** `docs/技术方案/模块设计/T02-项目数据库媒体和恢复.md`、`docs/技术方案/04-跨模块接口与数据约定.md`、`docs/开发记录/T01完成后的开发交接.md` 第 5 节。

## Global Constraints

- renderer 无 Node、无任意 IPC/HTTP、无令牌/后端端口、无已保存 Key/绝对磁盘路径。
- 每个连接 foreign_keys=ON、WAL、FULL、busy_timeout=3000ms；短事务不等待网络或复制大文件。
- 生产迁移 002 只建 projects、operations、drafts、media_files、import_intents、local_jobs 及其索引。
- 业务 JSON 上限 1MiB；运行时保持 64KiB 和 GET 无 body/query。
- 文件 grant 一次性、五分钟 TTL，绑定用途/窗口/会话；main 私有登记，renderer 不提交路径。
- 同 ID 相同请求返回原回执，不同内容 409；先查操作再校验 CAS/grant；响应丢失不换 ID 重写。
- 非空非项目目录、损坏数据库和不明确的恢复残留不得覆盖。原件和用户输入优先保留。
- 只启用实际交付能力；真实云调用另经预算授权。
