# T04 任务、费用与恢复实施计划

> **For agentic workers:** Use superpowers:subagent-driven-development to execute task by task.

**目标：** 每次生成都有固定输入、明确最高费用与用户启动；重复操作、断网、崩溃不会自动再次生成，账目与已得结果保留。

**架构：** 项目 004 迁移安装预算/计划/任务/调用/账目/上传表；应用单执行器持有跨项目活动槽。收费端口只由持久化任务状态机调用。固定响应适配器用于隔离的 synthetic 项目，真实网络适配在 T06/T10 按能力准入。

**依据：** `docs/技术方案/模块设计/T04-任务费用与恢复.md`、跨模块约定第 2/4/5 节、业务契约和 project.sql。

## 全局约束

- 所有收费分支只有 planTask → startTask；计划编译不调用模型、不上传。
- UUID 操作防重、CAS、回执与业务状态同事务；先识别项目/会话，再重放，再 CAS。
- CNY 非负整数微元；三重预算是项目、阶段、任务，阶段分配总额不超项目预算。
- 一个主动用户任务跨项目生效。未知/部分完成/确定失败停止未提交调用，原占用保留。
- prepared 重启不自动发送；submitting 无结果变 unknown，不再次 POST；已知远端 ID 只查询，已有结果只下载。
- 内容撤销、下载恢复和停止观察不减少费用；结算更正有追加事件和明确依据。
- 计划有效期 10 分钟；阶段/能力/模板/价格/输入改变后拒绝启动旧计划。
- 空白/未完成草稿仍可保存；收费启动前按阶段校验必需输入和参考，不要求生成结果字段预先存在。
- synthetic 与 real 不混账；默认未验证能力不得启用真实推理；无明确非零费用上限不创建真实计划。
