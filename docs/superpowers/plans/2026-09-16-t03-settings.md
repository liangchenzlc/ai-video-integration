# T03 凭据、能力与完整配置实施计划

> **For agentic workers:** Use superpowers:subagent-driven-development to execute task by task.

**目标：** 用户能配置加密凭据、媒体工具、生产音频存储和各制作阶段的模型，并看清账户、接口、效果各自的缺口。

**架构：** 延续有限 Electron 桥和 Python 应用库；设置 CAS 独立于项目 CAS。秘密只经写入路径进入后端，DPAPI 用户范围加密；能力档案与任务快照分离。项目迁移 003 在一致备份后增加 stage_models。

**依据：** `docs/技术方案/模块设计/T03-凭据能力与完整配置.md`、设计 OpenAPI、application.sql、project.sql、V03-01–05。

## 全局约束

- 已保存 Key 不回渲染层、不写入日志/URL/项目；提交后立即清空秘密输入。
- DPAPI 不可用只允许 session_only 或取消，禁止明文降级。
- 应用配置 CAS 使用 settingsRevision，项目 stage-models 使用 project.revision。
- 账户、接口、质量三种状态独立；没有真实证据不得标 verified。
- 仅已确定免费的账户/元数据请求可走 connection-checks；任何收费推理进入 T04 计划。
- OSS 保留期 1–168 小时，默认表单 48 小时；本批不执行上传、签名或清理。
- 现有草稿允许空白/未完成；配置和迁移不破坏草稿及媒体恢复。
- 保留旧项目/备份；不自动删除未知文件，不变更唯一原件。
