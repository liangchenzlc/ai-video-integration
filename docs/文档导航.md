## 当前状态

- 产品：Windows 本地、中文新手、BYOK、单条独立 AI 漫剧；质量优先，其次成本可控。
- 目标：写实人物与实拍式摄影空间，按题材需要加入视效。既有二维测试不代表最终影视目标。
- 已有证据：1 次文本、21 次图像、2 次视频云端推理，以及一次本地临时配音；两版 30 秒研究预演。
- 技术方案：前端 Electron + React + TypeScript，后端 FastAPI + Python；首版本机后端，当前展开 T01 主设计、接口/管道契约、工程步骤及候选版本。
- 尚未完成：应用代码、可点击原型、完整质量通过的模型组合、正式成片、实际账单核对、真人评审和新手试用。
- 当前无在途生成；本次文档整理没有调用模型，也没有改变测试费用授权。

## 维护规则

产品范围、流程、预算、架构与验收分别在负责的核心文档修改；涉及多个领域时同步相关约束。技术方案维护工程机制与当前模块详细设计，模块完成状态统一回写 05，不提前把所有模块写成已实现。新实测追加至附录和调用表，区分观察、推断、待验证与当前采用。不得把写入文档、API 成功、预演可播或个人接受写成正式质量已通过。
