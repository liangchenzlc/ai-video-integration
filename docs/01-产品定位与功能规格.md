# 产品定位与功能规格

文档基线：0.6，2026-09-15。本文统一定义产品目标与首版范围；操作细节见[制作流程与交互设计](./02-制作流程与交互设计.md)，当前实测情况见[验证记录与参考依据](./06-验证记录与参考依据.md)。文档要求不代表功能已经实现。

## 1. 产品目标

面向没有 AI 工具经验的中国大陆个人创作者，提供 Windows 本地桌面工作台，从故事文本完成一条独立 AI 漫剧。优先级为：**成片质量 > 成本可控 > 制作效率 > 精细控制**。

目标是用户认可的影视级 AI 漫剧：具备美术与材质、可信光影和空间、叙事镜头、角色动作与表演、剪辑和声音。用户提供的[《零号档案》参考资产](./资料/零号档案资产/)把当前视觉研究方向具体化为写实人物、实拍式摄影空间及按题材需要的科幻/超现实视效。雨夜、暗色、巨物或复杂打斗不是所有作品的要求；既有二维《雨夜借光》仅验证流程，不定义最终效果上限。

主要解决片内人物与场景不一致、提示试错费用难控、剧本到剪辑断链、局部问题引发全片返工、多工具搬运等问题。成本优化必须保持同一质量门槛，统计全部尝试并让用户了解已花、待结算、剩余制作和修改增量。不能以图片移动代替必要角色动作，也不能以输出分辨率宣称电影质感。

## 2. 产品形态与边界

| 项目 | 首版要求 |
| --- | --- |
| 平台与语言 | Windows 本地桌面；简体中文界面、创作、配音及字幕流程 |
| 项目单位 | 一个项目对应一条独立成片；片内资产复用与连续性 |
| 服务模式 | BYOK，用户自有服务商账户和 API Key；应用不充值、不代付，无自有生成云后端 |
| 输入 | 粘贴故事想法、小说片段或已有剧本；参考图、音频及替代视频在对应工作台导入 |
| 模型 | 少量经过适配的服务商，按阶段选择兼容模型；同阶段统一模型，无单角色/镜头覆盖 |
| 保存 | 项目和媒体本地保存；任务按需外发必要内容，凭据在应用配置独立加密 |
| 操作 | 向导和阶段工作台；自然语言修改及普通文本/基础剪辑编辑，隐藏提示词和 JSON |
| 执行 | 同时一个用户任务；当前对象有限候选串行、指定预检；不自动重试或跨阶段推进 |
| 交付 | 自动初剪、基础多轨、检查及 MP4；核心流程不要求应用账号 |

30 秒是验收样片规模，不是产品最大时长。初期验证少量角色、有限场景和简单动作；超出已验证长度、风格或复杂度须展示范围限制，重估成本与资源。模板标明真实已验证组合，自定义方向标为探索性。

以下不进入首版：连续剧/季度/IP 管理、跨项目资产库、多人协作和团队权限、SaaS/云同步/私有部署、自动发布运营、账号商业化和许可证系统、模型市场/任意接口/本地模型、跨镜批量队列与并发、专业调色/蒙版/复杂特效/专业混音、文档解析/网页抓取/批量文本导入、无限版本历史/用户快照/压缩备份/自动清理。基本撤销、最近确认基准恢复、数据库迁移备份和原任务恢复仍属于必要可靠性。

## 3. 创建与首次使用

首页提供新建、打开、最近项目和可离线浏览的预置示例。项目摘要包括当前阶段、推荐下一步、保存时间、目录、磁盘占用、预算与待结算、待处理问题。示例标明预置，不作当前模型效果证明。

创建时确认项目名称和目录、输入类型与原文、目标时长、16:9/9:16 画幅、目标受众、题材与效果目标。优先呈现文本、时长、画幅、效果，其他信息可使用明确可修改的建议。可补充必留人物/情节/台词、改编范围、输出模板和平台规范。默认 1080p、24 fps、通用导出；预算可先规划，首次付费前落实总额与阶段上限。

设置页提供推荐服务商申请指引、地域/权限/型号检查、音频传输及本地 FFmpeg/编码器配置。连接成功不代表完整制作链可用。首次付费前说明后续缺口；缺少服务时仍可浏览示例和准备本地草稿。任何收费测试或试听先说明范围与费用。

## 4. 核心功能

| 工作区 | 必须具备的功能与结果 |
| --- | --- |
| 故事 | 内容方案、大纲、分场与台词逐级审核；已有剧本保留原意，缺失部分才生成；原文、段落/场景/台词定位和改编差异可查 |
| 视觉与分镜 | 效果目标、角色/场景/道具、候选对照、固定特征和允许变化；镜头卡/故事板、稳定编号、关键帧用途与实际参考 |
| 镜头制作 | 全片静态预演、条件代表镜头试片、逐镜视频及适用口型处理；相邻镜头与原尺寸对照、问题定位、局部修订与采用 |
| 声音与剪辑 | 角色配音与字幕、音乐/音效上传或主动生成、素材可用区间、基础多轨及自动初剪 |
| 检查与导出 | 分阶段检查、证据与处理决定、必要复检、当前采用链检查和 MP4 输出 |
| 项目工具 | 统一任务进度/恢复、预算与调用明细、模型配置、保存/撤销/媒体重新定位 |

### 故事与制作依据

原文区分必留事实、允许改编和未决项。分析只覆盖当前片段，不冒充全书分析；超出模型输入能力在调用前说明，不能静默截断。四级审核不等于四轮强制重写。

必要动作、对白、声音、画内文字和揭示要求关联承载镜头；显示尚未安排项。有意省略或替代随内容修订采用，不能只因字段齐全就认为剧本无遗漏。物理事实、人物知情、观众知情分别处理，例如盒里有信不代表人物或观众已经看见。只为实际叙事需要记录释放事件、时间与可见/可听载体。

### 资产与镜头

同一身份的换装、伤势、天气、开合等按需记为持续状态，注明原因与生效范围；一次姿势不新建资产。同款物件如需分别交换或追踪，可以有独立身份。角色自身左右与画面左右分开。

镜头卡包含目的、观看重点、角色/场景、构图/摄影、起止与必要动作过程、视线/持物、对白、时长、能力要求和当前成果。关键场景可按需比较信息时机、观看位置或表演中心真正不同的方案，说明制作负担；普通场景不增加必填表或额外规划调用。

参考位显示真实图、版本和用途，区分待准备、已导入待核对、已核对可用、缺失/不适配。提示词不等于图片，文件可打开也不等于内容匹配。缺图仍可写草稿，但不能把依赖它的生成静默改成文生视频。关键帧区分构图参考、首帧、关键瞬间、结束状态，不能将动作完成图误作动作起点。

### 声音与时间线

按句生成、试听、修改或导入配音；提供模型支持的预设音色、情绪/语速/停顿/重音及授权音色克隆。控制不受支持时明确说明，不能收下参数却假称生效。

字幕默认取采用台词，转写只辅助定时；支持独立文字和时间编辑，保留与台词差异，单改字幕不自动重做配音。替换声音/视频后重核相关字幕时间。画内屏幕/纸张/标牌文字与后期字幕分开，记录准确可读、仅图形、不可读或内容待定及揭示时机，不承诺首版透视贴图或运动跟踪。

音乐、音效可上传、使用有许可的内置素材或主动生成；提供裁切、循环边界预览、淡入淡出、音量与对白优先混音。使用本地素材不等于 AI 生成分支已完成。

时间线包含图片/视频、配音、音乐、音效、字幕轨。提供播放/定位/吸附、移动/分割/入出点/时长、硬切/叠化/淡入淡出，以及位置、缩放、不透明度、音量简单关键帧。默认镜头条与常用控制，完整多轨按需展开，共享同一状态与撤销记录。再次自动编排先预览，不覆盖人工编辑。

原片观察与剪辑选择分开，标记已检查、可用和问题区间；未检查不显示通过。补拍补足明确要求，默认与原镜并存；替代版才请求更换当前采用。两者均保留原片、承载关系、采用影响和全部费用。

## 5. 输出与质量责任

| 规格 | 要求 |
| --- | --- |
| 横屏 | 720p：1280×720；1080p：1920×1080 |
| 竖屏 | 720p：720×1280；1080p：1080×1920 |
| 原始分辨率 | 指创建时选定的上述项目画布，不是任意尺寸或素材分辨率 |
| 帧率与封装 | 24/25/30 fps，默认 24；H.264 视频、有音轨时 AAC，MP4 |
| 字幕 | 默认烧录，可关闭；安全区、溢出与关键内容遮挡检查 |
| 画幅适配 | 默认完整适配并留边，裁切须预览确认；放大标为缩放，不承诺新增细节 |

不承诺 HDR、透明视频、单独字幕/音轨/素材包或第三方剪辑工程导出。覆盖同名成片先确认；中断保留项目，重导出不调用生成模型。

质量由技术可交付、一致性、艺术效果分别判断，不能用综合高分掩盖某个必要维度失败。普通偏差可在必要审核后明确接受，但不可交付问题和必要风险未知不能用主观接受绕过；用户接受有缺陷作品也不代表产品发布验收通过。详细门槛见[开发计划与验收标准](./05-开发计划与验收标准.md)。

## 6. 当前决定与开放问题

已确定首版范围、BYOK、六组导航、串行任务、采用/确认分离、局部依赖、全片预演、条件试片和基础多轨；架构采用前后端分离：前端 Electron + React + TypeScript，后端 FastAPI + Python，SQLite 与 FFmpeg 由后端管理。首版后端随桌面在本机运行，仍保持项目本地保存和 BYOK；详细实现见[技术方案](./技术方案/README.md)。

仍须验证用户最终认可的动态效果、完整模型组合、稳定生产音频传输、自然配音与精确口型、AI 音乐/音效、实际账单与同质量降本、真人评审和新手体验。应用实现尚未开始。近期研发可推进本地可靠性底座，不能将研究预演标为正式通过。
