# 模型接入与成本控制

版本 0.5，2026-09-15。本文是模型能力、调用授权和费用口径的统一依据。历史配置与实测见[验证记录与参考依据](./06-验证记录与参考依据.md)，不得把过去的测试授权当作未来无限生成授权。

## 1. 选择与能力边界

BYOK，服务商向用户计费；应用无充值、代付和自有生成额度。推荐少量已适配组合，尽量减少配置服务商数量，以相同质量目标下的完整尝试成本评选，不以低价、赠额或 API 成功代替质量。

按改编、大纲、分场、台词、角色/场景/关键帧、视频、配音、口型、音乐/音效和检查阶段选择兼容模型，同阶段统一。更换配置仅作用于新任务，不重写历史来源或强迫全阶段重做；新结果与旧片混用需检查一致性。

| 能力 | 调用前确认 |
| --- | --- |
| 中文内容 | 输入长度、忠实度、结构化成果、局部修改 |
| 图像 | 参考数量/顺序/用途、尺寸/画幅、编辑与人物场景约束 |
| 视频 | 首帧/尾帧/参考模式、互斥输入、时长档位、单镜头条件、音频和连续性 |
| 语音/口型 | 具体型号/音色、中文、情绪/时序范围、授权克隆、驱动或后续处理兼容性 |
| 音乐/音效 | 生成类型/长度、使用条款与可用本地替代 |
| 检查 | 实际支持的文本/图片/视频/音频范围及准确性限制 |
| 恢复 | 远端任务 ID、查询/取消、结果有效期、下载方式 |
| 成本/传输 | 地域/版本/计价单位、用量与账单、媒体输入和外部存储费用 |

账户连接、接口能力、实际生成质量和完整组合验证分别标记。不支持的参数/参考不能静默丢弃；缺口在付费前提示兼容阶段模型或经用户采用的内容调整。无完整能力可以准备本地内容或开展符合条件的局部研究，但不能宣称已可完成成片。

## 2. 当前候选与生产前提

当前首测入口为阿里云百炼（北京），研究组合为 qwen-flash、qwen-image-2.0、wan2.6-i2v-flash；视觉检查候选 qwen3-vl-flash 尚未推理测试。临时配音为 Windows Microsoft Huihui Desktop；cosyvoice-v3.5-flash 因无系统预设音色不适合原方案，替代候选 cosyvoice-v3-flash + longyingtao_v3 尚未调用。它们均不是已通过影视质量验收的正式组合。

2026-09-15 的资料与试测记录：wan2.6-i2v-flash 北京支持 2–15 秒整数时长；720P 有声/无声标价参考分别为 0.30/0.15 元每秒。该日期价格不作为永久现价，启用前复核。audio=false 即使传音频也不能显示已应用配音；单镜参数与实际输出均需检查。图像参考数按确切型号，曾读取的图像 3.0 编辑说明为 1–3 张，不能不加区分套给所有型号。

图像可按官方能力使用 Base64；当前百炼视频音频使用服务可读取的 URL，不能发送本地路径。临时上传仅研究使用（资料标注 48 小时、同模型和主账号、特定请求头），不冻结为生产方案。首版生产音频传输先验证用户自有 OSS 私有对象和短时签名链接，明确配置、费用及删除策略；或采用后续验证的正式稳定替代能力。未完成时云端对白制作受限，本地预演仍可继续。

视频/图像结果可能有有效期，按接口记录显示并及时下载；到期不保证找回。独立口型修复、AI 音乐/音效和可靠视觉检查仍待专项验证。Drama Skills 提及其他模型只是研究线索，不自动新增适配或切换账户。

## 3. 用户任务与调用授权

一项用户任务有明确对象和目标，可包括有限串行创作/生成与指定预检，不跨阶段自动推进。候选默认 1，用户可调整，只针对当前对象，不形成跨镜队列。

启动前展示对象/修改范围、实际输入与外发类别、模型、候选数量、最大生成调用数、预检内容/次数、费用区间、项目/阶段/本任务支出边界，以及失败处理。用户可一次授权列明的多次调用，不能解释为无限修复直到满意。

每次收费调用前重新检查剩余授权和预算。范围、输入基准或估算超过原授权时停下展示新范围；确定失败或结果未知停止尚未提交的调用，保留已有候选。未包含的付费检查单独启动。生成并预检不包含自动修复，也不因分数合格推进下一阶段。

本地模板拼装、确定的引用/能力核对、播放、编辑、混音和导出不调用生成服务。需要 AI 创作新镜头、理解复杂修改或方案比较则列明创作调用，不能藏在普通浏览或准备任务。一个授权任务包含多模态调用时，分别记录、保持当前对象边界；实质改变采用基准先进入修改采用规则。

## 4. 查询、下载与重新生成

原状态查询与下载属于原任务恢复，原授权覆盖必要步骤；服务商另收费时事先披露并纳入上限。有限自动查询可以恢复，不无限轮询；状态未知不假定失败。

重新提交生成是新费用行为，任何失败均不自动重生成。已知远端任务优先取回原结果；响应丢失且无 ID/查询能力时明确结果无法确定，提供时间和摘要供核对，用户理解重复收费风险后才决定新任务。

停止本地等待不承诺云端取消或退费；只有真实支持并返回取消结果才显示已取消。预算不足仍能恢复原结果，按已披露的查询/下载条件执行。项目撤销、换模型、废弃候选不回退云端任务或账目。

## 5. 账目与预算

每个服务调用保存对象/阶段、模型/地域/版本、请求及远端标识、时间、数量与用量、价格来源/日期、估价、占用、结算金额与依据、结果和费用状态。成功可能未结算，失败也可能收费。

| 费用类别 | 口径 |
| --- | --- |
| 已确认费用 | 服务商用量与计价或账单支持，注明依据 |
| 待结算占用 | 已提交且实际金额未确定，按已披露保守估计占用 |
| 未提交制作估算 | 未来计划，用于判断下一步和完工费用，不是已消费 |
| 返工情景 | 明确哪些对象追加多少候选/检查的假设增量，不是授权或统计保证 |

结算以实际金额替换占用，不重复累计。失败、未采用、质检、口型和用户重做全计入；部分候选返回按实际提交记录，不把未发出的调用算成花费。未知任务或失败费用继续占用，直到账单或手工核对有依据并记录原因。

用户设总预算，系统建议阶段分配，分配之和不超过总额，可留未分配余额。阶段转移不得低于已发生/占用金额。默认预警 80%，可调。项目余额、阶段余额、本任务上限任一不足，停止新收费提交；调高预算不自动执行。

外部账户余额及其他工具消费无法完整取得时说明。预算约束本应用的新请求，不保证强制限制服务商总账。动态用量按已知边界估算，若实际超出显示原因并停止后续付费，不能声称已截断账单。

没有价格不能按零或无限额启动。先补公开计价规则，或填写明确标为估算的保守上限；此值不是供应商账单保证。价格/时长/数量变化重新展示影响。

## 6. 完工预测与同质量降本

预计完工总额 = 已确认费用 + 待结算占用 + 未提交剩余制作估算 + 明确返工情景增量。

每个计划工作项关联当前输入、模型、数量、请求档位、检查与其他外部费用。提交后从剩余估算移至占用，结算后替换为实际金额；同一调用只出现一次。预测有版本及价格日期，不改历史账，不授权生产。

分镜未定标粗估；分镜/配音计时/模型档位/试片/采用修改后重算。一次通过情景与指定追加候选情景并列，不伪装置信区间。未知项保留，不把已知小计称为全片上限。预算低于基础估算时提前展示缺口、调整方案或只研究局部的选择。

分开叙事计划时长、请求与计费长度、返回实测时长和采用区间。例如模型只有 5 秒档而故事需 3 秒，显示请求 5 秒和计划保留 3 秒；裁剪不会退减生成费用。

降本顺序是前期叙事/分镜合理化、真实配音计时、已验证素材复用、已有可用区间剪辑、必要局部修订，再考虑新生成。每个方案显示叙事影响、新增调用/费用、人工处理和未知项；不能靠删必留动作、藏嘴或低清放大达到表面低价。补拍产生新调用，旧镜费用保留；复用不重复计费。

成本中心回答本次多少、已花多少、还需多少、修改增加多少。主界面常驻摘要，详情展开价格与调用。人工操作、模型等待、本地资源单列；存储与采购按来源纳入外部总费用，实际现金与无赠额标价分开。无合格成片/结算证据，不宣传固定每分钟价格、可靠采用率或已实现降本。
