# T13 安装、升级与诊断操作

本轮提供本地代码与内部构建入口；签名证书、实际干净 Windows 11 安装/升级/卸载验证及发布许可尚未验收。

## 构建与安装

`scripts/pack-win.ps1` 使用固定工具链构建 Electron 与 Python onedir，并生成实际文件哈希、依赖锁摘要和许可清单。`scripts/pack-installer.ps1` 生成用户范围 NSIS 安装包，默认保留用户配置，禁止自动发布。FFmpeg 不随包分发，用户在设置中选择兼容的本机构建。目录包保持整个目录，不单独移动 exe。

## 更新和回退

采用主动下载更新，不配置更新服务器或遥测。关闭当前应用后，先运行 `scripts/stage-update.ps1 -InstalledDirectory <旧程序目录> -RollbackDirectory <新备份目录>`，逐文件复制并核对哈希成功后再启动新安装器。脚本只操作程序副本，不按 python/ffmpeg 名称终止进程，不复制或删除项目。

项目写入打开时，升级前由 SQLite backup API 保存一致备份；008 迁移在事务中完成，失败回滚并保留备份。旧程序拒绝写入新版本 schema。回退程序不能直接降低项目 schema；需要使用兼容程序，或将明确选定的旧备份复制到新项目目录后再打开，保留原项目。

卸载仅卸载程序资源；项目目录和用户配置默认保留。用户数据清理没有绑定安装器。升级前程序副本由用户选择路径保留，可验证后自行管理。

## 诊断

设置页未打开项目时也可预览并导出运行环境诊断。项目诊断绑定发起时的项目与会话；切换项目清空预览与保存目标，原命令重试保留原项目编号，不能带入另一个项目正文。

页面先展示文件清单。默认只导出版本；可选项目状态计数，不复制数据库、日志、凭据或媒体。显式包含正文时仍移除已配置凭据、常见令牌、秘密键值（包括正文中的带引号 JSON/INI 字段）、URL和本机路径；用户预先知悉仍会包含创作内容。ZIP 只保存到原生选择的位置，不自动上传，不覆盖已有诊断文件。中断的诊断作业标记失败，不能显示交付成功。
