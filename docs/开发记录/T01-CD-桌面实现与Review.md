## 连接层子步骤

在接界面前执行 Vitest：74 项通过，包含真实 Node → Python supervisor → API 启动、认证健康、能力、重启和关闭。TypeScript 检查通过。接口客户端限制固定回环、两个路径、1500 ms 总请求时间、64 KiB 响应、无代理/跳转、精确头和 DTO；原始错误不会转发到界面。

生命周期检查覆盖双击重启合并、旧代际退出、关闭覆盖重启、晚到健康响应、连续三次失败、认证失败不重用旧令牌、8 秒停止截止、启动截止、版本失败和秘密哨兵。Review 修正了 spawn 事件前关闭时必须先发送 init 再发送 stop 的顺序。

异常 supervisor 退出的恢复依据：T01-A 已验证唯一不可继承 Job 句柄关闭时系统清理后代，因此已观察到当前 ChildProcess close 后允许用户明确重新启动；正常 stop 仍要求 stopped 与 close 同时成立。STOP_TIMEOUT 即使后来进程退出也禁止就地重启。
