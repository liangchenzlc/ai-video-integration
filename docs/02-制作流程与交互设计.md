# 制作流程与交互设计

版本 0.6，2026-09-15。本文统一制作依赖、页面行为及内部提示组织；范围以[产品定位与功能规格](./01-产品定位与功能规格.md)为准，费用授权以[模型接入与成本控制](./03-模型接入与成本控制.md)为准。页面仍为设计，未完成可点击原型或用户验证。

## 1. 主流程与审核关口

项目准备 → 内容方案 → 大纲 → 分场/台词 → 视觉资产 → 分镜 → 声音预制作与关键帧 → 静态预演 → 动态视频/适用口型 → 声音与剪辑 → 检查 → MP4。

阶段依赖由实际内容决定。已有成果、用户上传和不适用项经审核可以满足条件；审核通过不自动调用下一阶段。无对白镜头无需配音或口型。想法入口探索方案；小说片段明确范围与取舍；已有剧本先忠实提取，保留原意。

| 关口 | 必须确认的制作依据 |
| --- | --- |
| 项目准备 | 原文范围、简报、效果目标、时长/画幅、能力缺口、外发及预算 |
| 内容方案 | 所选方向、必留与可改内容、原文差异 |
| 大纲 | 冲突/因果、结局、结构与时长分配 |
| 分场/台词 | 角色目标、可见动作与状态变化、逐字台词及对白/VO/OS类型；无台词可不适用 |
| 视觉资产 | 身份锚点、服装/状态、场景地理/光源、道具形制与配套、参考用途 |
| 分镜 | 要求承载、观看重点、空间轴线、起止状态、动作/声音容量、模型兼容 |
| 声音/关键帧 | 配音发音情绪与实际长度；图像符合所用帧角色及镜头状态 |
| 静态预演 | 全片可理解、节奏/留白/声音位置及预计完工费用 |
| 动态制作 | 用户逐镜启动；实际视频动作、身份、声音和口型审核 |
| 剪辑/交付 | 必要内容完整、素材引用和检查有效、阻断问题解决、输出与预览一致 |

内容确认可在满足依赖时使用“采用并确认”，但候选选中不等于采用，采用不替代必要检查。

## 2. 页面地图与常驻信息

最低交互验证窗口为 1280×800，不是硬件配置承诺；空间不足时详情改抽屉，主预览与主要按钮保持可用。界面回答当前做什么、根据什么、是否可用、继续要花多少，隐藏 API、JSON 和内部提示词。

| 页面 | 导航/职责 | 主要动作与状态 |
| --- | --- | --- |
| P01 项目首页 | 全局入口 | 新建/打开/离线示例；目录、保存、未完成任务与问题 |
| P02 模型准备 | 全局设置 | 服务商、Key、地域、能力、音频传输、FFmpeg/编码器、价格 |
| P03 创建项目 | 项目准备 | 原文、时长、画幅、效果目标；其余建议可修改，付费前落实预算 |
| P04 故事 | 故事 | 方案/大纲/分场/台词；原文高亮、局部编辑、采用差异 |
| P05 视觉资产 | 视觉与分镜 | 固定特征/持续状态、候选对比、参考图准备 |
| P06 分镜 | 视觉与分镜 | 稳定镜头卡、关键帧、原文承载、动作/声音/揭示时机 |
| P07 静态预演 | 镜头制作 | 播放全片、定位镜头、调整时长/对白，确认后开放正式制作 |
| P08 动态镜头 | 镜头制作 | 单镜生成/适用口型、条件试片、原片和相邻对照、问题修订 |
| P09 声音与剪辑 | 声音与剪辑 | 配音/音乐/音效/字幕、原片可用带、镜头条/多轨 |
| P10 检查与导出 | 检查与导出 | 问题定位、补证/复检/处理、MP4 输出 |
| P11 成本与调用 | 项目工具 | 预算、已发生/待结算、剩余估算、返工情景与调用明细 |

共用面板：任务确认（界面 T01）、执行与恢复（界面 T02）、修改影响 M01、沿用与复检 M02、缺失文件 F01。界面面板编号与开发任务 T01–T14 属于不同命名范围。

工作区常驻当前成果、一个推荐下一步、保存反馈和可展开费用摘要。详情多时渐进展开，不增加多个竞争主按钮；浏览、播放、编辑草稿和本地保存不弹收费确认。

## 3. 视觉与镜头制作方法

### 资产、参考与状态

角色保存面部/体态/发型/服装等稳定识别点；场景保存地理、出入口、陈设与光源；道具保存数量、形制、材料、尺度、功能及配套关系。按镜头需要补视角，不要求所有项目都制作三视图。场景反打要维持地理，不能把换机位视为换场景。

持续状态含换装、伤势、天气、开合及持续支撑/固定关系，记录原因与生效范围。瞬时表情、姿势、视线、左右手和站位由镜头拥有。身份锁定不冻结表演；同一角色多视图不能变成多个人。

每个参考绑定具体文件版本、顺序、用途、保留项、允许变化与不得沿用内容。角色板的均匀照明不覆盖现场光，画风参考不应混入人物。多视图板只选实际需要的清晰视图或可预览局部，保存裁切与原图关系；放大不算细节恢复。超出真实模型上限先处理缺口，不能静默丢图。

| 参考/帧状态 | 界面含义与处理 |
| --- | --- |
| 提示已写、图片待准备 | 允许继续草稿；导入已有图或查看单项生成任务 |
| 已导入待核对 | 文件可读但内容/用途尚未确认，不按文件名认定匹配 |
| 已核对可用 | 绑定用途、版本与证据；适配检查仍必需 |
| 缺失/不适配 | 定位受影响镜头、重新定位文件或调整方案 |
| 构图参考 | 辅助设计，不自动是视频起点 |
| 首帧 | 投影动作发生前的准确状态 |
| 关键瞬间 | 展示某个必要事件，可供审核，不一定是模型输入 |
| 结束状态 | 投影完成后的状态；仅真实支持且传入才称结束帧控制 |

### 摄影、表演与信息

每镜先明确必须让观众读懂什么、谁拥有注意、切镜带来什么变化，再选择景别、机位、景深和运动。光线写光源/方向与可见受光结果，暗部保留应读信息；不按平均 RGB 或统一轮廓光定义电影感。远景不可仅靠细小眼神承载重大转折，多人反应来自不同立场和触发。

涉及接触/位移时写清发起、靠近、触碰、受力、落点、释放及必要反应。合理简化装饰动作，保留必留过程；人物、环境与摄影机运动分开。镜内几个时间段不自动变成多镜或多次调用。

物理存在、人物获得信息、观众获得信息分别安排。有揭示需求时记录来源、可见/可听载体、暂扣与释放条件；“后半段首次出现”绑定已确认目标时长。重排/删镜后重核画面、声音、字幕、反射，不提前泄露也不遮掉必须看懂的信息。

### 白话制作卡

    镜头：[名称与稳定编号]                 [定位原文]
    必须呈现：[动作、对白、声音或证据]
    观看重点：[主体与情绪]
    起点 → 必要动作 → 终点
    参考：[实际缩略图、用途、状态]
    时长：[叙事计划 / 请求和计费 / 发声窗口]
    信息时机：[需要时展开]
    缺口：[原因及处理入口]
    [编辑草稿] [查看本镜生成任务]

关键场景可按需比较“先看证据再看反应”等真正不同方案，展示观看体验和制作负担；不强制每镜多方案，不默认增加 AI 调用。

## 4. 对白、预演与条件试片

可见对白路径为已采用关键帧和配音共同驱动视频，或生成兼容视频后用独立能力处理口型。无兼容路径则停止该镜头正式付费任务，提供配置或经用户采用的改写选择，不能自动改为旁白。正式路径需验证，研究新能力可走下述条件试片。

旁白/画外音与视频分别制作。多人同时说话、遮挡和大侧脸另查能力，首轮只验证单个可见说话者。视频自带声音需选择采用内容，正式配音不叠加重复人声；无法分离时提示可用处理方案。

时长分为叙事计划、请求/计费、媒体实测、采用区间。对白按真实发声区间安排；没有录音时标文本估计，考虑开口等待、顺序动作、他人发声和末尾反应，句内停顿不重复扣除，合理并行可共享时间。比如配音 5.2 秒加前后各 0.6 秒需 6.4 秒，不能塞进 6 秒再声称已满足。超载先建议调整非必要动作、延长/拆镜或改台词，采用前显示影响，不能静默加速删词。

静态预演用采用关键帧、配音和临时字幕本地拼接，显示“静态预演”、总长/镜长/对白位置。临时音乐可用合法预置，不自动生成。确认全片后用户逐镜制作；生成档位不同需说明请求长度、计划保留区间和费用。

代表镜头试片只用于新效果、新组合或未验证关键动作，不是每个项目必经额外开销。它允许在全片预演前验证选定镜头，但必须满足该镜头文字、实际资产、关键帧、配音、局部预演、接口适配和预算条件。逐镜主动启动，列出多个代表镜计划不等于授权跨镜批量执行。分别记录艺术、动作、身份/声音结论；未达标不自动修复。通过且基准未变的已采用成果可复用，不重复生成。正式全片仍要求全片预演和必要能力验证。

## 5. 从制作依据组织提示词

用户表达意图，领域层保存采用的制作事实；系统本地按阶段模板和真实模型能力组织请求，不要求新手编辑长提示。需要理解复杂修改或创作新方案的 AI 调用必须列入任务，不能藏在准备过程。

| 阶段 | 模板应组织的内容 |
| --- | --- |
| 内容/改编 | 输入范围、必留/可改/未决、因果与观看目标、来源承载 |
| 人物 | 身份锚点、当前造型状态、用途/视角、形体与服装、背景边界和允许变化 |
| 场景 | 地理/出入口/固定物、空景与人物边界、观察方向、光源与受光结果、材料和天气 |
| 道具 | 唯一身份/数量、形制材料、尺度参照、功能接口、状态、文字政策 |
| 分镜图 | 来源要求、单一冻结瞬间、参考职责、视觉中心、空间层次、姿态与接触、光材及连续性 |
| 视频 | 锁定素材与静态锚点、起点、动作链与反应、摄影、声音/文字时序、终点；时间段按需 |
| 局部修改 | 目标对象/区域/时间、改动项、保持项、参考、补充或替代用途与承载要求 |
| 检查 | 采用基准、实际输入/媒体版本、必留事项、观察范围、具体问题与证据限制 |

模板默认建议不覆盖用户已确认事实；有冲突先定位到来源/状态，不悄悄折中。确定的约束优先本地校验，语义不明保留需核对。必要身份锚点不因参考存在就全删；不把整个项目与全部指南灌入单次请求。

适配记录实际参考数量、顺序、首尾帧/多参考互斥、尺寸/时长/音频、负面参数和语言。不能支持的条件明确展示为缺口或仅审核依据；文字描述结束状态不能冒称结束帧控制。关闭生成字幕与保留剧情屏显文字独立；声音用途分清配音驱动、仅参照音色或后期使用。

任务快照保存制作依据、模板/适配版本、最终请求和真实输入；旧任务不因模板更新被改写。敏感完整请求按项目正文保护，不进普通日志。

S04 示例：起点是左手握单个灯、猫背空槽；必要过程是靠近对齐、灯落座、手指松开并撤离；终点是手离开、灯独自留在背上。完成装灯图只能作终态审核或真实支持的尾帧输入，不作空槽动作首帧。改变摄影不能改成右手、复制灯或省掉松手；时间段是意图，不能证明模型精确执行。

## 6. 剪辑、补拍与字幕

先查看原片，标记观察覆盖、可用带、缺陷时间/原因，再选择入出点。抽帧未覆盖部分标未检查。裁掉起始等待或结尾漂移前，核对必要动作、台词、反应和揭示完整，不能为避错删戏。可用画面或声音允许单独复用，保存来源并检查接缝。

第一次初剪沿用预演。替换媒体默认保留位置、时长、入出点及字幕/音频关系；新媒体不足先给差异，允许保留旧结果、调整时长或另行生成，禁止偷偷拉伸/循环/冻结。更长素材选所用区间，镜头移动携带关联台词与字幕，全片音乐保持其轨道关系。再次编排只在预览并确认范围后执行。

补拍补一个具体动作/反应，默认不替换原镜；替代版需核对全部要求承载。新建或改变镜头回分镜修订及必要局部预演，作为单镜新任务启动。采用面板展示各片段承担什么、还缺什么，不能只因新增画面漂亮就把遗漏消除。

字幕正文默认采用台词，独立改字显示与台词差异，不自动改配音；声画替换重核定时。画内精确文字在其载体和出现时机上验收，与后期字幕开关无关。对白、音乐、音效、环境声按时间线处理去重、接缝和音量，不以提示词写了混音就视为已完成。

## 7. 修改、确认与恢复

修改草稿 → 展示差异/保持项/下游和成本影响 → 用户采用 → 相关成果待更新 → 用户修订或复检沿用 → 重新确认。未经采用不改变当前片；任务执行中允许无关编辑，但不能采用改变该任务输入的上游内容。

| 修改 | 应影响 | 通常保持 |
| --- | --- | --- |
| 角色外套改色 | 引用角色的视觉成果和检查 | 无关配音/镜头 |
| 台词改词 | 配音、字幕、可见对白视频与时长 | 无关背景 |
| 字幕标点或独立字幕修正 | 字幕、对应检查与导出 | 配音与生成视频 |
| 换音乐 | 音乐轨、混音检查与导出 | 剧本、关键帧、口型 |
| 重排/裁切 | 时间线、相关声音/揭示/要求覆盖检查 | 未改变的原始素材 |
| 仅换阶段模型配置 | 新任务能力和估价 | 旧结果来源与确认 |

沿用必须完成适用核对，不能一键抹去必要风险；撤销最近采用恢复基准及关联，保留所有已取得媒体和费用。

| 现象 | 给用户的动作和含义 |
| --- | --- |
| 提交超时、不知是否受理 | “结果待确认”，查询/核对原任务，不自动重新生成 |
| 原任务运行中 | 查看进度、有限继续查询；停止等待仅停止本地观察 |
| 云端成功但下载失败 | “结果待下载”，重新下载原文件 |
| 确定失败或原结果过期 | 说明原因与旧费用，用户另行启动新生成 |
| 部分候选完成 | 保留已得结果，停止未提交部分，用户决定缺失项 |
| 缺图/缺音频/缺编码器 | 具体缺口及导入/配置入口，保留无关本地工作 |
| 检查未知或疑似风险 | 补充依据或明确启动复检，不显示通过 |
| 保存/导出失败 | 本地空间/权限/格式处理，不因此重做云端素材 |

付费面板同时显示对象、修改范围、输入图/配音、模型、候选/调用上限、包含预检、外发、估价、预算和完工影响。恢复使用既有授权；普通浏览/本地编辑无需新确认。所有示例金额和模拟任务标记演示，不进真实账目。

## 8. 原型走查

在相关界面定稿前用预置素材验证完整配置、已有剧本、参考缺失、条件试片、字幕与角色修改、未知任务、下载失败、短素材替换、补拍替代、预算不足及导出问题定位。

观察用户是否能解释“当前采用哪版、本次花多少、完工还需多少、停止等待会怎样”，并独立找到处理入口。记录误操作/求助/耗时，不能用文字线框替代易用性证据。G00 与 T01-A/B/C 技术验证可分别推进，其相关走查在 T01-D 界面定稿前完成。原型不证明真实服务防重或崩溃恢复；正式验收见[开发计划与验收标准](./05-开发计划与验收标准.md)。
