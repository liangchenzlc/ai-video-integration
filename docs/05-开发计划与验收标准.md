## 3. 样片与能力准入

| 项目 | 初始验收基线 |
| --- | --- |
| 数量 | 三种输入各至少两个独立项目，共六条；至少两类题材，覆盖横竖屏 |
| 单条 | 30 秒 ±2 秒，6–8 镜，1–2 主要角色，至少一人跨 3 镜；一个主要场景 |
| 内容 | 简单可读的连续动作、至少一处可见人物中文对白，正式配音、字幕、音乐与必要音效 |
| 范围 | 首轮不承诺群像/复杂打斗/多人同时可见说话/高难长镜；超出范围另验证 |
| 模型 | 内容、图像、视频、声音及可见对白路径能真实衔接，参考确实参与，失败与恢复能力可说明 |
| 保留 | 第一次结果、失败、未采用候选、全部调用、修改与最终媒体 |

两组原创测试文本与镜头在[验证记录与参考依据](./06-验证记录与参考依据.md)。同一故事三种入口不是三个不同题材。二维样本验证流程；最终效果须按用户认可的写实影视目标另做代表镜头，不改历史失败来满足门槛。

## 4. 分层质量与合规

检查报告包括对象及采用版本、文本位置/图像区域/视频时间、依据、影响、严重性、置信/能力限制、建议范围及处理状态（待处理/修改中/待复检/解决/普通偏差已接受）。结构事实、语义义务、制作建议、审美选择分别标记；不能只给总分或无证据“电影感不足”。

先看原尺寸，再连续播放目标和相邻片段。技术交付、一致性和艺术效果分别判断：构图/空间、光材/色彩、重量/接触/表演、叙事镜头/剪辑及声音共同满足采用目标。两名人工评审独立看片，有争议定位复看；AI 分数不代决定。

严重缺陷不得存在：错换身份或未安排换衣、关键场景/道具错位破坏理解、明显畸变/消失/动作断裂、关键对白或字幕漏句/说话归属错、持续口型错位/重复人声/对白不清、黑帧/缺媒体/画幅错误/文件不可播、未解决阻断风险。

可测目标：

- 总时长 28–32 秒，台词的人名/数字/关键信息无错漏。
- 可见对白起止与嘴部活动偏差目标 ≤200 毫秒，仍须逐句看片；不等于音素级全同步。
- 字幕起止与配音偏差目标 ≤200 毫秒，无越界/遮挡必要信息。
- 无可听失真，音乐/音效不持续盖住对白，场景方向和道具状态有连续依据。
- 当前采用和输出与确认预览一致。记录方法、实测值和判断人，目标不能当已实现能力。

普通质量偏差允许用户记录原因后接受，不改写问题事实；这不代表发布测试通过。媒体缺失、损坏、必要未知不能这样绕过。新结果不继承旧质量，局部改动复查实际依赖。

合规检查有规则来源/版本/适用日期，默认通用导出，支持的平台选定后再附相应规则。区分确定阻断、疑似待核实、检查未知、通过；纯模型猜测不直接认定侵权违法。必要风险未核实不能导出相关内容，但可补授权/来源/解释或改稿后复检，不提供一键忽略高风险。用户声明不是自动免检，AI 疑似匹配不是确定结论；无复核能力如实说明，只阻断相关任务与采用链。

## 5. 关键行为验收矩阵

| 场景 | 预期 |
| --- | --- |
| 过长原文/已有剧本 | 付费前提示范围、不截断；已有内容不强制重写 |
| 无对白/缺口型能力 | 合理不适用；有对白缺能力在付费前阻止并给出口 |
| 同长度修改原文/未采用草稿 | 前者版本可辨，后者不影响当前片 |
| 30 秒作品“后半段首次可读” | 15 秒前不能通过画面/声音/字幕提前泄露，重排重新核对 |
| 5.2 秒发声+0.6+0.6 秒顺序事件 | 6 秒窗口缺 0.4 秒；估计与实测分开、不自动提速 |
| 提示词或同名未核对图片 | 不等于真实参考可用，不能静默转文生视频 |
| 原片末段漂移/补拍仅有特写 | 可裁完整可用带；不能裁掉松手或以特写替代必留过程 |
| 双击/受理后断网/下载中断 | 无自动二次提交；查询原任务、恢复原下载 |
| 撤销采用/更换素材 | 关联可恢复、费用不删；旧观察/字幕时间不错误继承 |
| 预算不足/未结算 | 新付费受限、原结果可取回；占用保留不双计 |
| 保存失败/目录移动/缺媒体 | 不虚报；相对引用可恢复，相关缺失阻止输出 |
| 检查未知/无关废弃候选 | 未知不标通过；无关问题不误拦当前成片 |

本地结构检查只能发现已知约束的冲突，不能承诺所有语义遗漏均被发现。单次“高质量”或固定动作数/语速不作普适规则；生产观察保留直接现象、可能原因、替代解释及改动/保持项。

## 6. 费用、效率与新手验收

同素材、可比模型、相同质量目标对照应用与手工多工具流程，交替执行减轻熟练度偏差。以完整项目统计失败、预检、未采用、口型、重做、文本规划，分开人工有效时间、模型等待、总耗时、操作数、调用数、采用率、返工、外部总费用/待结算及估算误差。

初始通过条件：配对人工时间中位数和总模型费用中位数均低于对照，一致性返工中位数不高于对照，成片通过同一质量门槛。记录实际改善比例，不设无依据百分比；账单未知不能宣称已降本。素材采购/存储、本地资源和人工投入按成本规则列明，不把赠额当长期免费。

新手测试记录完整配置、采用/修改/恢复/预算/导出求助点、误操作、用时和放弃原因。初轮五人至少四人无需代操作完成；原型模拟不代表真实恢复安全，试用成功也不是商业成功证明。
