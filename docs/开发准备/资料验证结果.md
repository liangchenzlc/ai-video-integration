## 3. 现在如何开始开发

1. 按 [T01 工程方案](../技术方案/模块设计/T01-工程实施与验证.md)核对并安装准确候选工具链，建立最小 frontend/backend 与锁文件。当前 Node/Python 资料工具环境不直接当生产版本。
2. T01-A 验证 Python supervisor、Windows Job、匿名管道与自带后端目录包；失败只处理工具链/进程问题。
3. T01-B/C 落地健康/能力 API、认证、契约生成和 Electron 生命周期，沿用正负例并增加真实运行测试。
4. T01-D 定稿前完成相关使用者 G00 走查；T01-E 汇总进程/安全/打包证据，才进入 T02。
5. T02 起使用本轮模块基线和 synthetic 夹具开发；真实服务启用必须按对应能力档案和费用授权，不能将占位适配器标成生产完成。

无需先补齐所有真人样片、购买服务或找回历史原件才开始 T01。应用任务完成情况继续只在 05 更新，当前仍全部待实现。
