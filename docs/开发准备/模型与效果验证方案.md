# 模型、动态效果与成本验证方案

日期：2026-09-15。状态：可执行实验设计；没有新增真实模型调用，没有价格重查或人工通过结论。

## 1. 先验证的三个代表场景

| 场景 | 固定输入与必留要求 | 观察和通过依据 |
| --- | --- | --- |
| R01 可见中文对白 | 一个成年写实角色、胸上近景、已采用身份图与正式普通话配音；完整说“别怕，我借你一点光。” | 原尺寸连续播放，身份、皮肤/光线、自然表情、完整声音、逐句嘴部活动；目标起止偏差 ≤200ms，另记停顿乱动嘴，不只看波形相关 |
| R02 道具接触 | 同一人物左手持单个灯；靠近空槽、落座、松指、撤离；不增加灯或省掉过程 | 接触、受力、手侧、唯一性、起终状态都可见；保留原片，记录可用与问题区间，不能用跳切代替原动作通过 |
| R03 跨镜连续性 | 同一人物/服装/空间的中景、近景、反应镜；灯光按剧情改变 | 同人不同景别仍一致，空间轴线及道具位置可解释，光线变化有来源；分别评艺术与一致性 |

现有《雨夜借光》可以保留故事事实并另设写实资产基准；不得覆盖原二维版本。风格选择暂取写实人物、可信材质、克制视效，等待实际试片反馈。首轮先测 R01/R02，每个镜头主动启动；R03 的各镜仍是独立用户任务。建议计划默认每对象一个候选、最多追加一次，具体费用授权到有准确模型/输入后再呈现。

## 2. 可用模型档案必须具备的字段

providerId、modelId、region、capabilityVersion、checkedAt、文档来源、accountCheck、interfaceCheck、qualityCheck；三种检查独立。每个阶段说明输入模态、真实参考角色与最大数量/大小、画幅/尺寸、时长档位、音频格式、音色/语言、取消/查询能力、结果有效期、价格单位/币种/日期和用量来源。

为每个正式适配提供脱敏的成功响应、受理后未知、确定失败、限流、部分候选、过期 URL、下载失败样例；接口不支持的行为明确标 unavailable，不能构造假接口当官方能力。

当前 qwen-flash、qwen-image-2.0、wan2.6-i2v-flash 只作历史研究候选。cosyvoice-v3-flash + longyingtao_v3、视觉检查和 AI 音乐/音效仍待验证。代码先提供 disabled 状态，只有真实能力与规则落实后才能启用对应路径。

## 3. 生产音频传输验证

首选研究用户自有 OSS 私有 bucket：最小对象权限、随机对象键、HTTPS 签名、输入大小/时长上限、模型地域适配和账单归属。输入先上传后记录，签名有效期应覆盖已测排队、生成、恢复窗口并留余量，不用固定短期限假定足够。有效期不足不得提交。

验证链接在服务商侧可读取；运行中/结果未知不删对象；本地崩溃后根据 upload_id 找到对象；成功且不再被任务引用后按已披露保留期删除；删除失败可再次执行原清理，不调用生成。保留上传/存储/流量成本项。凭据仅本机加密，签名 URL 不入普通日志。

## 4. 评审表

每条记录：sampleId、inputRevision、mediaHash、评审人、日期、原尺寸播放范围、对象/时间位置、直接观察、严重性、参考依据、通过/失败/未知、建议改动与保持项。技术、一致性、艺术、声音分别结论，不使用综合分遮盖失败。

用户接受普通瑕疵要记录原因，不能替代发布通过。AI 可以辅助抽帧和提示观察点，不能填写独立真人姓名或伪造听审。已有静态参考只支持构图、材质和光线方向的研究，不证明动态效果。

## 5. 成本与六项目对照

沿用 06 的 B01–B06 两个故事、三种入口、横竖屏独立项目。手工流程和应用流程使用对称参考、可比模型、同质量要求，交替顺序。每次记录全部调用/失败/未采用、真实账单或 pending、人工有效时间、等待、总时长、操作数与修改原因。

先建立单镜完整成本，再做单条完整片，最后做六条配对评测。没有合格样片或待结算仍未知时，不输出每分钟价格和节省比例。初始公开门槛仍为人工时间/总模型费用中位数低于对照、一致性返工中位数不高于对照。

工程可用固定响应与本地素材继续；适配接口编码不等于质量准入。T08/T10/T11 的真实分支和 T14 必须取得对应证据。测试费用、账户或效果选择成为必需时，再向用户提出包含对象、调用次数和费用上限的具体问题。
