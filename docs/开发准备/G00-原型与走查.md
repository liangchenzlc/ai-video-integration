# G00 原型与走查

设计基线 0.1.0，2026-09-15。[打开离线原型](./原型/index.html)。静态 HTML/CSS/JavaScript，无后端、外部资源、模型调用、真实凭据或真实账目；本页刷新重置。

## 1. 已实现的原型范围

六组导航、配置说明、新建演示项目、故事确认、角色修改草稿/放弃/影响预览/采用、当前镜头任务计划、未知结果与停止等待、原下载恢复、预算不足、参考缺失、短素材替换、字幕独立修改、检查与导出设置说明。

图片/视频来自仓库已存在的二维研究素材，明确标注未通过正式质量验收。原型中的价格是演示数字，确认操作只改变浏览器内存，不写项目、不触发 FFmpeg 或服务商。导出界面只能预览规格，不给出虚假下载。

这份原型验证关键状态和入口，不覆盖完整剪辑器拖拽、所有故事编辑、真实账户/OSS 设置、全部检查复核或已实现的桌面安全。当前测试 Chromium 不支持研究 MP4 的 H.264 解码，原型显示抽帧封面、明确错误及原文件入口；这不算视频播放通过。后续 T01-D 与业务模块按实际功能继续走查，T09 验证 Electron 内真实播放/代理。

## 2. 视觉与可访问性决定

参考 ui-ux-pro-max 的深色低亮度和清晰焦点建议；工作台按任务布局，不采用其检索输出中的营销 hero、远程字体或无实测转化率结论。普通 CSS、系统中文字体、低饱和绿色主动作，警告同时用文字表达。

1280×800 为主走查尺寸；窄屏以单列和可滚动导航保持入口可达。文字/按钮高对比、表单有 label、原生 dialog 键盘可关闭、焦点可见，支持 reduced-motion。正式 Electron CSP/沙箱仍按 T01 实测，本原型 CSP 禁外网和表单提交不等于桌面安全通过。
