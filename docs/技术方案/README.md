# 技术方案导航

方案版本：0.3，2026-09-15。对应本次更新的文档基线 0.7，未变更的流程、模型及历史证据仍沿用原版本。前端 Electron + React + TypeScript，后端 FastAPI + Python，采用前后端分离与本机后端部署。当前交付为技术方案，应用代码和可点击原型尚未开始；文中的目录、接口与命令均为拟实施约定。

## 1. 本目录解决什么问题

把[技术架构与数据规则](../04-技术架构与数据规则.md)展开为可逐模块落地的工程方案：先明确技术选择和系统边界，再为当前模块完成设计、开发、验证与复盘，然后进入下一模块。

当前详细设计范围止于 **T01 桌面启动、安全和导航**。后续模块在路线图中保留职责、依赖和交付关口，到启动时再确定其表结构、接口细节和开发步骤。产品首版的完整范围继续保留，阶段交付不等于完整首版发布。

## 5. 维护方式

模块文档采用稳定编号，例如 `模块设计/T02-项目数据库媒体和恢复.md`；只有启动该模块详细设计时才创建对应文件。编号与开发任务 T01–T14 一一对应，界面面板的同名编号不适用。

每次模块交付记录设计变更、准确版本、验证命令与结果、已知限制和下一模块输入。完成状态统一回写原开发计划的复选框，避免在多个进度表中分别维护。模型证据更新至原验证附录；普通工程测试证据在对应模块交付记录中引用。
