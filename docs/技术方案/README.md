# 技术方案导航

方案版本：0.4，2026-09-15。对应文档基线 0.8。前端 Electron + React + TypeScript，后端 FastAPI + Python，首版本机部署。当前已有 T01–T14 设计基线、机器可读业务契约与离线 G00 原型；T01 桌面底座与目录包验证已完成，T02–T14 尚未实现。

## 1. 本目录解决什么问题

把[技术架构与数据规则](../04-技术架构与数据规则.md)展开为可逐模块落地的工程方案：先明确技术选择和系统边界，再为当前模块完成设计、开发、验证与复盘，然后进入下一模块。

本轮按用户授权提前补齐 **T02–T14** 需求、接口、数据、实现批次与验证示例。T01 保留原工程设计。实际开发仍逐模块完成，不提前部署所有业务表或接口；设计验证不表示完整首版已经实现。

## 6. 维护方式

模块文档采用稳定编号，与开发任务 T01–T14 一一对应。已有基线直接维护，不按开发会话复制新版本文件；界面面板的同名编号属于不同范围。

每次模块交付记录设计变更、准确版本、验证命令与结果、已知限制和下一模块输入。完成状态统一回写原开发计划的复选框，避免在多个进度表中分别维护。模型证据更新至原验证附录；普通工程测试证据在对应模块交付记录中引用。
