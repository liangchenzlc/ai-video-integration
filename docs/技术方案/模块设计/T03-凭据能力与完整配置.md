# T03 凭据、能力与完整配置

设计基线 0.1.0；待实现。前置 T02。目标：用户理解整条制作链需要哪些服务和工具，并能安全配置；连接成功不会被显示成质量通过。

## 1. 需求与交互

设置按“文字/图像、声音、视频与口型、音乐音效、媒体工具”展示可用与缺口。默认研究候选不等于正式推荐。用户输入 Key 提交后立即清空表单；读取接口只给 configured/maskedSuffix。切换区域或型号必须重新检查对应能力，现有结果来源保留。

连接检测按钮先显示检测内容；仅已确定免费的账户/元数据请求可走 connection-checks。任何收费试听/推理均转 T04 任务计划。服务缺失仍可打开示例、编辑和使用已导入素材。

## 2. API 与数据

`GET /settings` → Settings；`PUT /credentials/{providerId}` → SetCredential；`POST /credentials/{providerId}/delete`；`PUT /settings/media-tools` 使用 ffmpegGrantId；`PUT /settings/storage` 使用 bucket/region/credentialRef/retentionHours；`POST /connection-checks` 返回 global job；`GET /jobs/{jobId}` 查结果。项目 `PUT /stage-models` 只改变新任务所用 capabilityId。

准确字段见 [OpenAPI](../契约/business.openapi.json)，样例查 setCredential、configureStorage、configureStageModel。应用配置写命令 CAS 使用 settingsRevision，项目 stage-models 使用 project.revision，不能混用。

应用库持有 settings、credentials、capabilities、storage_profiles、recent_projects、global_operations/global_jobs。凭据 DPAPI 密文为 BLOB，不随项目移动；session_only 不写库。capabilities profile 使用 Capability Schema，版本更新后旧任务保留所用完整快照。项目迁移 003 建 stage_models，只存 capabilityId/version，不依赖 T04 预算表；历史使用的快照不依赖当前配置仍存在。

凭据录入使用 CredentialSecret 区分 api_key 和 oss（accessKeyId/accessKeySecret/可选 securityToken），不要求用户把多个秘密拼成字符串。整个 secret 标 writeOnly，写入加密前后均不能进入日志/响应。stage-models 按 PipelinePhase 配置，预算 Stage 不参与细分模型覆盖。

## 3. 能力与传输规则

账户、接口、质量三种状态独立；enabled 必须至少满足账户和接口可用，生产任务另要求用途对应 qualityState=verified，research_only 仅条件试片。图像参考数量和角色、video audio 开关/时长档位都来自确切模型档案。不能支持的控制给明确缺口。

OSS 使用用户自有 bucket，secret 进入凭据库；region/bucket/保留期可读取，签名 URL 不回 renderer。默认保留期建议 48h，仅用于用户配置初值；运行/未知任务引用不受到期清理影响。签名窗口按已验证排队和处理时间另算。

FFmpeg 原生选择后检查 ffprobe、H.264/AAC 编码、libass、实际构建来源；缺字幕编码不能显示完整导出已就绪。构建校验在隔离本地作业进行，不拼接 shell。

## 4. 故障与安全

DPAPI 不可用只允许 session_only 或取消，禁止明文降级。密文换设备不可解密→重新录入；删除旧 Key 不删媒体账目。错误地域、无预设音色、无语音传输、账户权限不足、FFmpeg 缺失各有具体出口。诊断过滤请求体、授权头、签名地址及 SDK 异常回显。

## 5. 实现与验证

批次：应用配置/CAS → DPAPI/秘密隔离 → 版本能力档案 → 免费连接检查与完整配置引导。固定假档案先开发；官方接口与真实账户验证单列。

| 示例 | 输入 | 预期 |
| --- | --- | --- |
| V03-01 | DPAPI 加密失败 | 明文零落盘，表单清空/错误明确，用户可选本次使用 |
