# T08 配音、字幕与时间容量

设计基线 0.1.0；待实现。前置 T07。目标：按句生成或导入配音，校准字幕，提前识别镜头放不下对白的问题。

## 1. 用户需求

台词按说话者和 visible/VO/OS 类型展示，试听能定位句子。音色、情绪、语速和停顿仅展示当前模型真实支持项；音色克隆另核证据。导入与生成并列，付费试听仍走任务授权。采用新录音前展示哪些字幕和视频要复检。

字幕默认取采用台词，允许独立改字并显示差异；转写只辅助定时，不能覆盖原台词。无可靠词级时间戳时提供句级/manual，不伪称逐字精确。

## 2. 接口和数据

导入复用 T02 imports；云语音复用 T04 stage=speech；内容更新复用 T05。SpeechPayload 存 dialogueId/text/speakerAssetId/mediaId/measuredMs/voicedRanges/timingMethod/voicePreset/notes，SubtitlePayload 存 audioRevisionId、timingMethod、cues。实际 WAV/MP3 等媒体格式在 media_files 探测。

`POST /timing-checks` TimingRequest → TimingResult，纯本地：shotRevisionId、speechRevisionIds、beforeMs、afterMs；返回 requiredMs/plannedMs/shortageMs/method/suitable。不写费用。单说话者顺序对白 required=全部实际录音占用+前后留白；录音内部停顿已计入，不再加一次。复杂并行按镜头 events 的时间布局检查，不能套简单求和。

录音全长用于容量，voicedRanges 用于嘴部/字幕时机，两者不能混淆。估计录音标 estimated；取得真实音频后自动使估计检查过期，但不自动改镜头或重生成。

## 3. 采用和恢复

采用新 speech revision：dialogueAudio、subtitleTiming、visible 对白视频待更新；VO/OS 不误影响口型。只修改 subtitle cue 文本不动 speech/call；改时间只影响字幕和输出检查。媒体重新定位哈希不同要走新 revision，不继承旧定时。

错误包括声音来源缺失、格式不兼容、无预设音色、发声窗口不足、句子映射未知。提供导入、重新校准、延长/拆镜/改台词选择；禁止自动提速、吞字或改旁白。

## 4. 验证

批次：导入与探测 → Speech/Subtitle 草稿采用 → 本地容量 → 真云语音适配 → 声音和嘴部人工准入。

| 示例 | 输入/操作 | 预期 |
| --- | --- | --- |
| V08-01 | 5.2s 配音+前后各0.6s，6s镜头 | required=6400、shortage=400、suitable=false |
| V08-02 | 配音中已有0.5s停顿 | 不再次把0.5s加到 required |
| V08-03 | 字幕“别怕”改“别怕，” | 配音调用数不变，differsFromDialogue 可查 |
| V08-04 | 替换录音为更长素材 | 定时检查过期，不偷偷截尾或加速 |
| V08-05 | 无字级时间戳 | 界面显示句级/手动精度，未填听审不通过 |

Windows 临时配音只可用于工程验证。正式自然听感、情绪、发音及口型目标依照模型验证方案执行。
