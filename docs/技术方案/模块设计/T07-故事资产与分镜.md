# T07 故事、资产与分镜

设计基线 0.1.0；待实现。前置 T05/T06。目标：把原文转成有来源、可审核、能实际制作的镜头，用户可以局部修改而不失去原意。

## 1. 页面和流程

三入口：想法探索方案、片段明确改编范围、已有剧本忠实提取。内容方案/大纲/分场/台词逐级审核，有成果可直接核对，不强制四次重写。左侧原文与来源定位，中间当前内容，右侧保持项和未安排要求；每阶段只有一个推荐主动作。

资产卡区分人物/场景/道具/风格；候选、身份锚点、允许变化和持续状态。参考显示真实缩略图、用途、版本与核对状态。镜头卡显示观看目的、起点/事件/终点、对白、摄影、时长、承载要求和所需参考，不让用户填 JSON。

## 2. 数据模型

StoryPayload：sourceText/sourceHash/inputType/approvalLevel/brief/outline/requirements/scenes/dialogues/adaptationNotes。SourceSpan 的 start/end 是原始 Unicode 码点半开区间；换行、中文和 emoji 必须正确定位。原文改动后旧范围待核对，不自动沿用相同 offset。

AssetPayload：身份固定点、允许变化、带起止 ShotId 的持续状态、参考。一个姿势不新建 asset；需分别追踪的同款道具用不同 assetId。

ShotPayload：shotId、sceneId、assetRevisionIds、requirementIds、startState/events/endState、subjectHand、camera、plannedMs、dialogueIds、references、videoMediaId、pickupOfShotId/use。事件注明 visual/audio/subtitle/screenText 载体及 physical/character/audience 观察方，不把“物理存在”当“观众已经知道”。

迁移 007 的 shots 是稳定编号与排序索引，内容真相在 revision。重排事务先暂移序号到不冲突区间再写目标 0…N-1，更新相关时间线与揭示影响；不重建 ShotId。删镜改为内容采用/时间线移除，保留原版本和来源。

## 3. 接口

正文/资产/分镜复用 saveDraft/createRevision/previewAdoption/adoptRevision；生成走 T04。`PUT /shot-order` 必须恰好包含当前所有活动镜头且无重复；`GET /coverage` 列未承载/未决要求和不可用参考；`POST /references/verification` 只写指定 draft 的核对结果，必须匹配媒体与用途，之后仍需采用。

必留项有意省略/替代进入 requirements.decision 和 adaptationNotes，不能仅隐藏警告。verifyReference 的 matchesPurpose=false 保持不可用，true 仍需适配数量/尺寸校验。上述字段和响应以 [OpenAPI](../契约/business.openapi.json) 为准。

## 4. 模板与业务规则

模板有稳定 ID/version 和阶段输入 Schema；本地组织只使用已采用事实及实际参考。角色模板强调身份/当前状态，分镜图只表达单个冻结瞬间，视频模板表达动作链。生成阶段的“禁止字幕”与剧情画内文字政策分开。单镜支持上限不足时先拆解建议，再由用户采用分镜修订。

条件试片只放行选定镜头已确认文字、资产、帧、正式配音、局部预演、接口和预算；全片生产还需全片预演。未变基准的已采用试片可复用。关键场景方案比较可主动启动文本创作任务，普通镜头不多加必经费用。

## 5. 验证与交付

批次：来源/三级内容数据 → 资产与真实参考 → 镜头/承载/排序 → 局部修订与试片准入。

| 示例 | 输入 | 预期 |
| --- | --- | --- |
| V07-01 | 已有剧本保留 1 句台词 | 原字句、来源和改编差异可查，不强制重写 |
| V07-02 | 必留“松手”，镜头只写落座 | coverage 保留缺口，不能确认完整承载 |
| V07-03 | 灯已装好图作为动作首帧 | 用途/起点不符，不能静默发图生视频 |
| V07-04 | 同长度替换人物名 | sourceHash 变，旧 SourceSpan 重新核对 |
| V07-05 | 揭示要求后半段，重排到开头 | revealTiming 失效，不修改原视频 |
| V07-06 | 补拍新增一个手部特写 | 新 ShotId/use=supplement，不自动替换原镜或消除剩余义务 |

交给 T08 明确台词归属和计划时长；交给 T09 稳定镜头与素材引用。叙事语义需要人工/AI 内容审核，结构验证不能宣称覆盖所有遗漏。
