# T06 文字、图像与结果取回

设计基线 0.1.0；待实现。前置 T05。目标：用户针对当前内容或资产取得可对照候选，全部输入、结果、用量和失败可追溯。

## 1. 需求与 API

生成/局部修订/AI 预检复用 T04 planTask/startTask/getTask/recoverCall，不增加能绕过预算的 `/generate`。`GET /tasks/{taskId}/candidates` 返回 CandidatePage；候选预览通过受控媒体协议，采用走 T05。用户可以导入已有媒体作为候选输入，经用途核对后使用。

自然语言修改先形成明确的修改意图；如需 LLM 理解，则在任务 steps 展示创作调用，再产生候选/影响预览。不能在打开页面或计算计划时悄悄调用模型。

## 2. 服务适配接口

Python 端口：describe_capabilities()→Capability；estimate(input_snapshot)→逐 step 微元上限；prepare_inputs(snapshot, upload_refs)→PreparedRequest；submit(request, submission_token)→Accepted(remoteId)|SyncResult|Unknown；query(remoteId)→RemoteStatus；download(resultRef)→流。适配器不得自行决定采用、重试生成、修复或新增参考。

内部 PreparedRequest 保存 capability/模板版本、reference 的顺序/角色/媒体哈希、确切参数及请求摘要。供应商响应先校验类型、大小、必要字段；LLM JSON 未满足 StoryPayload/AssetPayload 等时保存原始失败资料，返回结构不合格，不自动买第二次修复。

## 3. 数据与媒体

复用 service_calls/events、cost_entries、revisions、media_files、revision_media。每个候选由 task/call/ordinal 唯一追踪，实际返回少于请求数时只登记已得结果并停止未提交动作。完整请求属于受保护项目资料，普通日志只写 ID 和状态。

HTTPS 下载域/重定向逐跳核对，禁止私网/本机/凭据元数据目标，DNS 解析与实际连接 IP 一致；限制 MIME/长度/解码和超时。禁止将响应 URL 直接交渲染窗口。下载落 staging 后哈希/探测/原子发布，失败恢复原下载。

## 4. 本地示例与验证

使用标 synthetic 的结构化文本、有效 PNG/损坏文件和假远端状态开发。历史 qwen 图像仅作案例，真实参考上限以对应版本官方资料和测试为准。

| 示例 | 输入/故障 | 预期 |
| --- | --- | --- |
| V06-01 | 模型只支持 1 参考，任务必要参考 2 张 | 计划拒绝，显示兼容缺口，零提交 |
| V06-02 | 结果 JSON 少必留动作字段/结构不合法 | 保留原响应，候选不可确认，不自动修复 |
| V06-03 | 云端成功、下载断开 | pending_download；第二次仅下载，同 call/cost |
| V06-04 | 302 重定向到 127.0.0.1 | 拒绝，原任务保留，无内网连接 |
| V06-05 | 2 个候选只返回 1 个 | 一个候选可看、任务部分完成，不补跑 |

批次：固定响应适配 → 输入编译/快照 → 安全下载 → 候选对照 → 对应真实接口准入。交付包含脱敏适配 fixture；真实质量单独记在 06，不由 HTTP 200 推断通过。
