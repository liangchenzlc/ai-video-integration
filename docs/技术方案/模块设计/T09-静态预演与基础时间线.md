# T09 静态预演与基础时间线

设计基线 0.1.0；待实现。前置 T08。目标：用户在购买全片视频前看懂故事、节奏和对白位置，并以同一套时间线完成基础剪辑。

## 1. 交互与范围

默认镜头条，可展开图片/视频、配音、音乐、音效、字幕轨。支持播放/定位/吸附、移动、分割、入出点、时长、硬切/叠化/淡入淡出，以及位置/缩放/不透明度/音量简单关键帧。原片观察区间与剪辑采用区间分开显示。

第一次初剪依据采用分镜和配音；再次编排先创建时间线候选和影响预览，确认后才替换。镜头移动携带关联对白字幕，全片音乐保持其全片轨道位置。图片可按镜长停留；视频短缺不能冻结/循环冒充足够素材。

## 2. 数据与 RenderPlan

TimelinePayload 包含画布/fps/duration/tracks/clips/transitions/burnSubtitles，Clip 引用 mediaId 或 contentRevisionId、shotId、关联 clip 和 keyframes。视频/声音默认速度 1，durationMs=outMs-inMs；图片及字幕使用独立显示时长。Scale>0，opacity 0…1，volume 0…4，x/y 画布坐标；同 clip/property/time 不可重复关键帧。gainDb 与 volume keyframes 相乘，削波检查在实际混音后执行。

同轨 video/image clips 除已声明转场外不能重叠；声音轨可叠加但检测重复人声。dissolve 必须恰好等于相邻片段重叠，cut=0；fade 为该片段已有区间淡入/出而非凭空延长。分割保留 media/source in/out 和关联来源，字幕跨切点需预览拆分结果。

RenderPlan 是后端从已采用 timeline revision 生成的不可变编译结果，包括媒体哈希、轨道时序、字幕、简单关键帧与转场；缓存键由 timeline hash+媒体哈希+编码配置+编译器版本组成。索引 timeline_indexes 只是查询投影，不允许独立编辑。

## 3. API 与执行

时间线编辑走 T02 draft/T05 revision 与采用。`POST /animatics` 接受 timelineRevisionId → 202 local job；`POST /timeline/replacement-preview` 接受 timelineRevisionId/clipId/newMediaId，返回 shortageMs、affectedClipIds、requiredChecks、canPreserveEdit。原片观察保存 ObservationPayload。

媒体预览通过 main 私有协议支持 Range，代理生成走本地重媒体作业；前端不得以 Base64 搬完整视频。预演显著标“静态预演”，本地导出无模型费用。采用动态片段后仍使用同一时间线，输出类型和质量标记按实际构成。

## 4. 时间、性能与错误

全部区间半开、毫秒存储，帧量化沿用共用约定。项目画幅只能是合法横竖尺寸对，素材默认完整适配留边，裁切必须预览。解码不支持时提供兼容转码本地 job；无工具不能伪装播放/导出成功。

固定夹具覆盖七镜 30秒、24fps、720帧；同时测试长项目保护值（例如 100镜/10分钟）记录启动、拖动、seek、内存和导出时间，不把测量规模当首版支持承诺。代理分辨率不替换原件，预览帧和导出取样比较需作为应用验收。

## 5. 验证与交付

批次：时间线/编辑撤销 → 媒体代理播放 → RenderPlan/静态预演 → 转场关键帧 → 替换影响与重编排。

| 示例 | 输入 | 预期 |
| --- | --- | --- |
| V09-01 | 4+4+4+5+5+4+4 秒七镜 | 30,000ms；24fps 为720帧 |
| V09-02 | 原 clip 5秒，新视频3秒 | shortage=2000；旧剪辑保留，不能自动循环/冻结 |
| V09-03 | 重排有对白镜头 | 相关 voice/subtitle 移动，全片音乐不跟镜头走 |
| V09-04 | 29.999秒附近边界量化 | 共用边界不产生黑帧或重复一帧；零长必需片段拒绝 |
| V09-05 | 采用时长改变后撤销 | 全部 clip/关联恢复，原素材与成本不变 |

交付可播放静态预演与预览/导出一致性报告；不能据此宣布动态成片通过。
