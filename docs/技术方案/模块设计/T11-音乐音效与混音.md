# T11 音乐、音效与混音

设计基线 0.1.0；离线工程已实现，基础验证与外部验收边界见[本轮记录](../../开发记录/2026-09-16-T08-T13实现与验证.md)。前置 T08–T10。目标：为作品提供有来源的音乐/音效和清楚的声音层次，同时保留 AI 生成分支的实际准入要求。

## 1. 用户流程与范围

用户可导入、选有许可的内置素材或主动生成音乐/音效。生成 stage=music/sfx 仍走 T04，不因进入剪辑页面自动调用。内置素材首轮使用明确来源的本地合成工程样例；不能把临时音符当正式 AI 音乐能力。

声音轨支持裁切、移动、循环边界试听、淡入淡出、音量和对白优先混音。循环是用户明确编辑音乐片段后创建可见片段，视频短缺不能自动套同规则。输出前播放循环接缝和对白叠加区间。

## 2. API、数据和混音语义

导入走 T02、生成走 T04、声音采用和时间线编辑走 T05/T09。`PUT /rights/{evidenceId}` SaveRights 写素材来源/用途/证据关联；evidenceId 必须与 body 一致。权限声明不能自动将风险结论置通过，state=verified 需要对应核对记录和理由。

媒体来源在 media_files，许可记录在 rights_evidence；剪辑在 TimelinePayload clips/keys/gainDb。对白优先按钮本地生成可预览的音量包络草稿：在实际对白区间对音乐降幅、短 attack/release，参数可调整；采用后成为普通 keyframes，不另建第二套隐藏混音状态。叠加同一原片的人声和正式配音默认告警，不自动假定哪条是正确音轨。

## 3. 检查与故障

本地检测削波、时间空洞、已知重复声音源、字幕/配音超片长；自然听感、对白清晰和情绪仍需实际试听。来源不明素材标未核对，只影响其当前采用链。缺 AI 音乐能力时保留发布缺口，允许无关本地工作继续。

## 4. 验证与交付

批次：导入/来源 → 音量/循环/包络 → 本地混音检查 → 经验证 AI 音乐音效适配。
